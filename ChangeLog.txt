## 钢材重量计算器 — 项目迁移说明

版本: v3
更新日期: 2026-06-15

---

### 📁 文件清单（迁移需全部复制）

| 文件 | 用途 | 必需 |
|------|------|------|
| index.html | 主程序（单文件，含 CSS + JS + 数据） | ✅ |
| ChangeLog.txt | 更新日志 | 选 |
| images.png | 标题栏 Logo | 选（无图不影响功能） |
| 个人.png | 询价采购弹窗图 | 选 |
| 公众号.png | 公开招标弹窗图 | 选 |

---

### 🚀 部署方式

1. 复制所有文件到目标目录
2. 直接用浏览器打开 index.html 即可运行
3. 无后端、无数据库、无依赖，纯静态 HTML
4. 适合部署到：本地文件夹 / Nginx / GitHub Pages / 任意静态托管

---

### 📐 支持品类（14类）

H型钢: HN窄翼缘 / HM中翼缘 / HW宽翼缘 / HT薄壁 / BH组焊
型钢:   IB工字钢 / CH槽钢
角钢:   EA等边 / UA不等边
管材:   CHS圆管(含DN镀锌管) / SHS方管 / RHS矩形管
条材:   FL扁钢 / RB圆钢

---

### 🔧 功能模块

- 快速查重: 搜索规格 → 输入长度/数量 → 自动算重 → 累积明细
- 品类快捷标签: 搜索框下方14个品类按钮，点即展开该品类全部规格
- 自定义计算: 焊接H型钢、方矩形管、圆管、角钢、钢板、扁钢、圆钢
- 计算明细: 底部悬浮合计栏，支持查看/删除/清空
- 项目委托弹窗: 公开招标 + 询价采购入口

---

### ⚠️ 迁移注意

- 默认规格库为「国标常用」子集（约400+条），非全量国标
- 图片缺失不会报错，Logo 加载失败自动隐藏
- 移动端优先设计，推荐手机浏览器使用
- 所有数据硬编码在 index.html 的 DATA 对象中，修改规格直接编辑即可

### 2026-06-15 — 品类快捷标签 + Bug 修复 + 数据全面整理

#### 八、新增品类快捷标签

搜索框下方展示 14 个品类标签按钮（按 CAT_SORT 排序），点击即展开该品类全部规格：
- 标签换行排列，点击高亮变蓝，再次点击收起
- 点击其他标签自动切换，互斥高亮
- 开始输入搜索时自动清除标签高亮，进入搜索模式
- 清空搜索框或点「取消」回到标签初始态

#### 九、CHS 数组语法 Bug 修复

第 790-791 行修复两处 JS 语法错误导致页面完全无响应：
- 第 790 行：["CHS219.1x8.0 (DN200)",41.65],, → 去掉多余逗号
- 第 791 行：["CHS219.1x10.0 (DN200)",51.56] → 行末补上逗号

#### 十、致命 Bug 修复 — CAT_SORT 引用错误

const CAT_SORT 定义在第 1007 行，但 init() 在第 973 行调用，renderCatTags() 访问 CAT_SORT 时因 const 暂时性死区抛出 ReferenceError，导致整个 JS 脚本中断，页面所有功能瘫痪。

修复：将 CAT_SORT 定义提前至 init() 调用之前。

#### 十一、14 个品类数据排序矫正

重新排列所有品类规格，统一按尺寸升序排列：

| 品类 | 排序规则 | 问题 |
|------|----------|------|
| HN/HM/HW/HT/BH | 宽度 → 高度 → 米重 | 之前按高度排列，同宽度散落各处 |
| RHS 矩形管 | 长边 → 短边 → 壁厚 | RHS400x300x8 在 x10 之后 |
| SHS / RB / IB / CH / EA / UA / CHS | 原有规则，补米重二级排序 | 同尺寸排序不严谨 |

#### 十二、扁钢(FL)精简

移除 5 条宽度≥120mm 的较大规格（工程中很少用到）：
- 移除：FL120x10、FL120x12、FL150x10、FL150x12、FL150x16
- 保留：FL10x3 ~ FL100x12（宽度 10~100mm），共 30 条

#### 十三、BH 品类重命名

BH（组焊H型钢）规格名统一加 BH 前缀：
- H300x200x8x12 → BH300x200x8x12（共 25 条）
- 与其他 H 型钢品类（HN/HM/HW/HT）命名格式保持一致

### 2026-04-14 — 规格库重构

#### 一、DN 规格格式修正

DN 类别全部 46 条从 DNxx Dxx.xx 改为 DNxx CHSxx.xx。后来 CHS+DN 合并时这些又进了 CHS 数组。

#### 二、CHS + DN 合并为统一圆管类别

- DN 全部 46 条并入 CHS 数组，格式为 CHS21.3x2.8 (DN15)
- CHS 数组按外径→壁厚排序
